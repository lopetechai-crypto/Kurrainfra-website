# AMARIS by Kurra Infra — Luxury Residential Experience

> An architectural poem in Hyderabad's Financial District. Rising 50 storeys with two iconic G+50 towers, 4BHK sky residences with private plunge pools, and an 81,840 sq.ft. signature clubhouse.

---

## 🏛️ Project Highlights

- **300-Frame Hero Sequence**: Smooth scroll-scrubbed cinematic arrival animation.
- **Architectural Specifications & Scale**: Interactive 4x2 stat metrics with counters and blended twin tower facade atmosphere.
- **Why Choose Amaris**: Expansive 2x2 borderless architectural gallery and luxury privileges.
- **Experience Amaris**: 10 curated visual chapters with directional reveals and ambient warm lighting.
- **Mastered Layouts**: 12 architectural floor plans with interactive enquiry modal form and validation.
- **Prime Location & Connectivity**: Live Google Maps iframe embed, category destination filters, and direct Google Maps link.
- **Single Continuous Scroll System**: Restrained Lenis smooth scrolling synchronized with GSAP ScrollTrigger and lag-free scrub handoff.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Obsidian Luxury Theme
- **Motion & Scrolling**: GSAP 3 + ScrollTrigger + Lenis
- **Icons**: Lucide React

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/lopetechai-crypto/Kurrainfra-website.git
cd Kurrainfra-website

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
